# agent-accounts

This CLI is both a GitHub repo and an npm package:

- GitHub: https://github.com/tmrk/agent-accounts
- npm: https://www.npmjs.com/package/agent-accounts

Install the published CLI with:

```bash
npm install -g agent-accounts
```

That provides the `aacc` and `agent-accounts` binaries. For local development, work in this checkout (`npm test`, `npm start`). README screenshots are fictional demo data generated by `npm run screenshots`; never commit real account emails into `docs/screenshots/`.
